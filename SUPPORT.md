# Support

PYTHON HUB is an early-stage project. Support is currently provided through GitHub.

- **Bug reports:** use the Bug Report issue form.
- **Feature proposals:** use the Feature Request issue form.
- **Security concerns:** follow the private process in [SECURITY.md](SECURITY.md).
- **Usage questions:** open a discussion or a support issue when GitHub Discussions is unavailable.

Include your operating system, Python version, installation method, relevant command, and a sanitized error message. Never include passwords, access tokens, private keys, or personal data.
